# Даша (@asdasha_bot) — дизайнер корпусной мебели

Дизайнер мебели из Абакана, ведёт канал @abakan_mebel, работает в abakanmebel.online.
Консультирует строго по корпусной мебели: кухни, шкафы-купе, гардеробные, прихожие,
материалы (массив, ЛДСП, МДФ), фурнитура, стили и планировка.
Работает в среде OpenClaw, развёрнута в GitHub Actions 24/7.

## 🏗 Архитектура

OpenClaw Gateway (Node.js, **опционально**) → OpenAI API на localhost:18789.
Если шлюз не запустился — бот продолжает работать через прямые провайдеры
(Pollinations → Cloudflare Workers AI), ноль простоев.

Цепочка устойчивости AI: OpenClaw → Pollinations POST → Pollinations GET → Cloudflare.
Circuit breaker: после 3 неудач шлюз отключается на 10 минут, а не тормозит каждый вызов.

## 🛡 Стабильность

- Падение шлюза не роняет бот-процесс (раньше: `sys.exit(1)`)
- Circuit breaker для OpenClaw (мгновенный fallback)
- Дедупликация постов: news_id + URL + title fingerprint + topic fingerprint + text fingerprint + file backup
- Фильтр релевантности: в канал идут только мебельные новости
- Минимальная длина поста (250+ знаков) — короткий AI-ответ отбрасывается, берётся следующая новость
- Флуд-контроль: rate-limit на чат + RetryAfter
